# Prendas

Notebook de introduccion a Keras con Fashion-MNIST.

## Abrir en Google Colab

1. Sube o abre este repositorio desde GitHub en Colab.
2. Ejecuta la primera celda del notebook.
3. Autoriza el acceso a Google Drive cuando Colab lo solicite.

La primera celda monta Drive en `MyDrive/Prendas` cuando se ejecuta en Colab. En VS Code conserva la carpeta local del proyecto.

## GitHub

Desde esta carpeta:

```powershell
git add .
git commit -m "Inicializa notebook de Keras"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git push -u origin main
```

Reemplaza la URL por la de tu repositorio de GitHub.
